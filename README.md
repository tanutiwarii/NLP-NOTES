# NLP Notes

This repository contains Jupyter notebooks covering fundamental concepts in Natural Language Processing (NLP).

## Notebooks

1. **1-Basic_NLP.ipynb** - Introduction to basic NLP concepts and techniques
2. **2-Text_Normalization.ipynb** - Text preprocessing and normalization methods
3. **3-One-Hot_Encoding.ipynb** - Implementation of one-hot encoding for text data

## Requirements

- Python 3.6+
- Jupyter Notebook
- NLTK (for text processing)
- NumPy
- Pandas

## Installation

```bash
pip install nltk numpy pandas jupyter
```

## Usage

Open the notebooks in Jupyter and run the cells sequentially to follow along with the examples.
